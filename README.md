# Medical Shop Inventory Management System

A full-stack web application to manage medicine inventory. This application allows users to add, view, update, and delete medicine records in real-time. It features a responsive React frontend and a robust Node.js/MySQL backend.

## 🚀 Features

* **CRUD Operations**: Create, Read, Update, and Delete medicine records.
* **Real-time Validation**: Form validation for negative numbers, empty fields, and character limits.
* **Responsive Design**: Modern UI that works on desktops and mobile devices.
* **Database Integration**: Persistent data storage using MySQL.
* **RESTful API**: Clean API architecture using Express.js.

## 🛠️ Tech Stack

**Frontend:**
* React.js (Vite)
* CSS3 (Custom Flexbox/Grid styling)
* Axios (HTTP client)

**Backend:**
* Node.js
* Express.js
* MySQL2 (Database client)
* Cors & Dotenv

**Database:**
* MySQL
